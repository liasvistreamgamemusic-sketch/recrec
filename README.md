# recrec

オーディオインターフェースの全入力を、**入力ごとに別々の WAV ファイル**で同時に録る、
ミュージシャン向けの録音専用アプリです。Windows 用・無料・広告なし・オープンソース (GPL-3.0)。

- **ASIO / WASAPI 対応** — オーディオインターフェースを ASIO で直接録れます
- **入力ごとにモノラル WAV** — In1 のマイクと In2 のギターが、頭のそろった別ファイルになります。
  In3+4 をステレオ 1 ファイルにする、といった組み合わせも自由
- **16bit / 24bit / 32bit float** — 24bit 入力はビット単位で無劣化。16bit は TPDF ディザ付き
- **プリロール** — 録音ボタンを押す前の最大 30 秒もさかのぼって録れます
- **落ちても録音が残る** — ヘッダを 1 秒ごとに更新し、異常終了したテイクは次の起動時に自動修復
- **長時間録音** — 4GB を超えると自動で RF64 に切り替え。録音中はスリープしません
- **流れる波形表示** — トラックごとに直近 10 秒の波形が流れ、録音中は赤、クリップは黄色で分かります
- **メトロノームとカウントイン** — テンポ・拍子・タップテンポ。カウントインのあと小節の頭から録音が始まります。
  クリックは出力にだけ流れ、録音ファイルには入りません
- **モニター・ミュート・ソロ** — トラックごとに「聴く / 聴かない」を切り替え。音量とパンも調整できます (録音には影響しません)
- **その場で聴き直す** — 録音を止めるとテイクの波形がタイムラインに開き、クリックした位置から再生できます
- **一時停止・続きから録音・途中から録り直し** — 止めて再開しても 1 つのテイクのまま。閉じたテイクの続きも録れます。
  録り直しは元のテイクを残したまま、新しいテイクを作ります
- **マーカー** — 録音中に `M` キーで印を付けると、DAW でもマーカーとして見えます
- **テイクの整理** — 名前の変更、メモ、ごみ箱への移動
- **無音のトラックは残さない** — 何もつないでいない入力のファイルを自動で省きます (設定で切り替え)
- **DAW へドラッグ** — 録ったファイルをウィンドウから DAW へそのままドロップ
- **BWF タイムスタンプ** — 録音開始時刻をファイルに記録 (対応 DAW では元の時間位置に配置できます)

## インストール

[Releases](https://github.com/liasvistreamgamemusic-sketch/recrec/releases) から次のどちらかをダウンロードします。

| ファイル | 内容 |
|---|---|
| `recrec-<版>-setup.exe` | インストーラー。管理者権限は不要 (ユーザー単位でインストール)。スタートメニューに登録され、アンインストールもできます |
| `recrec-<版>-windows-x64.zip` | ポータブル版。展開して `recrec.exe` を実行するだけ |

コード署名をしていないため、初回は「Windows によって PC が保護されました」と表示されることがあります。
「詳細情報」→「実行」で起動できます。ダウンロードしたファイルは `SHA256SUMS.txt` で照合できます。

### アップデート

起動時に GitHub へ最新バージョンを問い合わせ、新しい版があれば画面上部でお知らせします (録音中は新しいお知らせを出しません)。

- インストーラー版: 「更新」を押すとインストーラーをダウンロードし、SHA256 を照合してから更新して開き直します
- ポータブル版: 「ダウンロードページを開く」から新しい zip を入手してください
- 「このバージョンをスキップ」でその版の通知を止められます。確認そのものは、サイドバーの「アップデート」→「起動時に確認する」でオフにできます

送信するのは GitHub への問い合わせだけで、録音や設定の内容は送りません。

## 使い方

画面は 3 つの列でできています。

| 列 | 内容 |
|---|---|
| 左 | **オーディオ** (ホスト・デバイス・サンプルレート・バッファ) と **録音** (形式・プリロール・出力先)、**出力** (アプリから出る音の音量)、ディスクの空き |
| 中央 | 録音ボタンと経過時間、メトロノーム、その下に **トラック** の一覧と波形・レベルメーター |
| 右 | 録り終えた **テイク** の一覧 |

1. 左の列で **ホスト** (`ASIO` 推奨)・**デバイス** を選びます。緑の点と「接続中」が出れば準備完了です
2. 中央の「トラック」が、録音されるファイルの一覧です。既定は「入力 1 つにつき 1 トラック (モノラル)」です
   - 左端の丸 … 赤なら録音する、灰色なら録音しない
   - 名前 … ファイル名になります (例: `Vocal` → `01_Vocal.wav`)
   - ソース … `In 1` のようなモノラル、または `In 3+4 (ステレオ)`
   - メーターが赤い領域 (-6 dB 以上) に入らないよう、インターフェース側のゲインを調整します。`CLIP` が出たらクリックで消せます
3. 大きな赤い丸 (または **Space** キー) で録音開始、もう一度押すと停止
4. 右の「テイク」でファイル名のチップをつかんで DAW へドラッグします。テイク名の左の点々をつかむと全ファイルをまとめて運べます

### 4 入力のオーディオインターフェースの例

| 入力 | つなぐもの | トラック設定 |
|---|---|---|
| In 1 | ボーカルマイク | `Vocal` / In 1 |
| In 2 | ギター (Hi-Z) | `Guitar` / In 2 |
| In 3-4 | シンセ (ステレオ) | `Synth` / In 3+4 (ステレオ) |

### メトロノーム

録音ボタンの下の帯で設定します。

1. スイッチをオンにし、テンポ (数値をドラッグ、または「タップ」を曲に合わせて数回クリック) と拍子を決めます
2. 「カウントイン」で小節数を選びます。録音ボタンを押すとカウントが鳴り、**次の小節の頭から**録音が始まります
3. 「録音中も鳴らす」をオフにすると、カウントインのあとクリックが止まります

クリックは Out 1-2 から出ます。**録音ファイルには入りません** (ファイルに書くのは入力の音だけです)。
ただし次の 2 つの場合は混ざります。

- **ループバック入力を録音している場合** — PC の再生音を録る入力 (機種によっては In 5 以降) はクリックも拾います。
  使わないならそのトラックを削除してください。使う場合は、トラックの調整メニュー (スライダーのアイコン) で
  「ループバック入力」に印を付けておくと、混ざるときに警告が出ます
- **スピーカーの音をマイクが拾う場合** — クリックはヘッドホンで聴いてください

メトロノームがオンのときは小節の頭から録るため、プリロールは使われません。
DAW に並べたとき演奏がグリッドより少し後ろにずれる場合は、左列の「録音開始の遅延補正」を増やします
(インターフェースの入出力の遅れぶんで、多くは 10〜20 ms 程度)。テンポは `take.json` に記録されます。

### モニター (アプリ経由で聴く)

ふだんはオーディオインターフェース本体のダイレクトモニター機能を使うのがおすすめです (遅れがありません)。
アプリ経由で聴きたいときは、トラックのヘッドホンのボタンをオンにします。

| ボタン | 働き |
|---|---|
| 赤い丸 | 録音する / しない |
| ヘッドホン | この入力をアプリ経由で聴く / 聴かない |
| M | ミュート (聴こえなくする。録音はされます) |
| S | ソロ (このトラックだけ聴く。録音は全トラックされます) |
| スライダー | モニターの音量とパン |

アプリ経由のモニターは少し遅れて聴こえます (バッファを小さくすると遅れが減ります)。
ダイレクトモニターと同時に使うと二重に聴こえるので、どちらか一方にしてください。
これらはすべて「聴こえ方」だけを変え、録音されるファイルは変わりません。

### 聴き直す・続きから録る・録り直す

録音を止めると、そのテイクが中央のタイムラインに開きます (右のテイク一覧の ▶ でも開けます)。

| 操作 | 方法 |
|---|---|
| 再生 / 停止 | トラックの上の ▶ ボタン、または **Enter** |
| 位置を動かす | 波形か時間の目盛りをクリック / ドラッグ。**Home** で先頭へ |
| 拡大 / 縮小 | 「＋」「−」ボタン、または波形の上で Ctrl + ホイール。「全体」でテイク全体を表示 |
| 横に移動 | 目盛りの下のバーをドラッグ、または Shift + ホイール |
| 入力の波形表示に戻る | 右端の × |

再生中もミュート (M)・ソロ (S)・音量・パンが効きます。再生はアプリの出力 (Out 1-2) から出ます。

- **一時停止 (P キー、または録音ボタン横のボタン)** — 録音中に押すと、テイクを閉じずに書き込みだけ止まります。
  もう一度押すと同じテイクの続きに録ります。つなぎ目にはマーカーが入ります
- **続きから録音** — テイクを開いた状態で「続きから録音」を押すと、そのテイクの最後に続けて録ります。
  サンプルレートが録音時と同じで、同じ入力がある場合に使えます
- **ここから録り直す** — 録り直したい位置を波形でクリックしてから押すと、その 4 秒前から再生が始まり、
  その位置から録音に切り替わります。**元のテイクはそのまま残り**、「元の音 (その位置まで) + 新しい音」の
  新しいテイクが作られます。つなぎ目は 5 ms のフェードでつながります

大きな赤い録音ボタン (Space) は、テイクを開いていても常に**新しいテイク**を録ります。

### マーカーとテイクの整理

- 録音中に **M** キーを押すと、その位置に旗が立ちます。WAV の cue ポイントとして保存され、対応する DAW でマーカーとして読めます
- テイクの鉛筆のボタンで、名前の変更・メモの追加・ごみ箱への移動ができます
- テイク一覧の右上の `»` で一覧を折りたたむと、トラックの波形を広く表示できます

### ループバック入力と無音のトラック

- 「リセット」で作られるトラックは、物理入力が録音オン、ループバック入力 (PC の再生音を録る入力) が録音オフです。
  ループバックを録りたいときだけ、そのトラックの赤い丸をオンにします
- 左列の「無音のトラックは保存しない」がオンのとき、テイクの最初から最後まで -60 dB を超えなかったトラックの
  ファイルは残りません (何を省いたかは通知と `take.json` に記録されます)。全トラックが無音のときはそのまま残ります

### 保存先

既定はミュージックフォルダの `recrec` です (「出力先」の「変更…」で変えられます)。

```text
recrec/
  2026-11-10_223015/          ← テイク (録音開始時刻)
    01_Vocal.wav
    02_Guitar.wav
    03_Synth.wav
    take.json                 ← デバイス・形式・長さ・取りこぼし数などの記録
  2026-11-10_224102_サビ案/    ← テイク名を入れた場合
```

### 困ったとき

| 症状 | 対処 |
|---|---|
| ASIO でデバイスを開けない | 他のアプリ (DAW など) が ASIO ドライバを使っていないか確認し、「⟳ 再接続」 |
| 状態欄に「取りこぼし」が出る | バッファを大きくする。録音中は重い処理を避ける |
| 録音中に PC が落ちた | もう一度起動すると自動で修復されます (失うのは最後の約 1 秒) |
| ログを見たい | `%LOCALAPPDATA%\recrec\data\logs\recrec.log` |

設定は `%APPDATA%\recrec\config\config.json` に保存されます。

## ソースからビルド

Rust (stable) が必要です。

```sh
cargo test
cargo run --release                      # WASAPI のみ
cargo build --release --features asio    # ASIO 対応 (Windows)
```

ASIO 対応ビルドには LLVM (libclang) が必要です (`LIBCLANG_PATH` を LLVM の `bin` に設定)。
ASIO SDK はビルド時に Steinberg のサイトから自動で取得されます。

設計は [docs/superpowers/specs/2026-11-10-recrec-design.md](docs/superpowers/specs/2026-11-10-recrec-design.md) にあります。
