# recrec 設計書 — 出力エンジン・メトロノーム・モニタリング・波形表示

- 作成日: 2026-11-11
- 前提: `2026-11-10-recrec-design.md` (録音エンジン)、v0.2 の UI
- 状態: 承認済み (2026-11-11)。VST は対象外、クリックは Out 1-2 固定・録音中は切り替え式

## 1. 目的と、これまでとの違い

v0.2 までの recrec は「入力を録るだけ・音は出さない」アプリだった。今回の要望は次の 4 つで、
どれも **アプリから音を出す** ことが前提になる。ここが最大の設計変更である。

| 要望 | 必要になるもの |
|---|---|
| メトロノームとカウントイン | 出力ストリーム、拍に同期した録音開始 |
| DAW のような波形表示 | 入力のピーク履歴 (出力は不要) |
| トラックのミュート | アプリ経由のモニタリング (聴こえている音を消す = アプリが音を出している) |
| 録音まわりの機能を一通り | 上記 + マーカーなど (§7 で範囲を決める) |

変えないもの: **録音の信頼性を最優先する**方針。音を出す側で何が起きても、
生の入力 (ドライ) はこれまでと同じ経路でファイルに書かれ続ける。

## 2. 範囲

v0.3 として一度に入れる: 出力エンジン、メトロノーム/カウントイン/タップテンポ、モニタリング
(ミュート・ソロ・音量・パン)、波形表示、マーカー、テイクの名前変更・メモ・削除。
互いに依存しており、まとめて設計しないと作り直しになるため。

## 3. 出力エンジン (v0.3 の土台)

### 3.1 構成

```text
 入力コールバック ──▶ 録音用リング ──▶ 書き込みスレッド ──▶ WAV (ドライ。従来どおり)
        │
        ├──▶ モニター用リング (SPSC) ──┐
        └──▶ 波形用リング (SPSC) ──▶ UI │
                                       ▼
 出力コールバック ◀── ミキサー (トラックごと: ミュート/ソロ/音量/パン) + メトロノーム
        └──▶ Out 1-2
```

- ASIO: 入力と同じドライバに出力ストリームを開く (cpal 0.18 は同一ドライバの入出力同時利用に対応 —
  `host/asio/stream.rs` の `get_or_create_output_stream` が既存の入力とまとめてバッファを作り直す)。
  入出力は同じクロックで動くので、ずれが溜まらない。
- WASAPI: 既定の出力デバイスに開く。入力と出力のクロックが別なので、モニター用リングの残量を見て
  余りを捨てる/足りなければ無音を足す。メトロノームと録音の位置合わせは「おおよそ」になる (UI に明記)。
- 出力先は **Out 1-2 固定** (決定済み)。
- 出力を開けなかった場合: 録音は従来どおり使える。メトロノームとモニターを無効にし、理由を表示する。
- 出力コールバックも入力側と同じ規則 (メモリ確保・ロック・I/O をしない)。設定値はアトミックで渡す。

### 3.2 録音への影響を断つ

- 録音用リングと書き込みスレッドには手を入れない。モニター用・波形用は別のリングで、
  あふれても捨てるだけ (録音の「取りこぼし」には数えない)。
- ミュート・音量・パン・メトロノームは **出力にだけ** 効く。録音ファイルの中身は変わらない。

## 4. メトロノームとカウントイン

| 項目 | 仕様 |
|---|---|
| テンポ | 30〜300 BPM (0.1 刻み)。タップテンポ (直近 4 回の間隔の平均) |
| 拍子 | 分子 1〜12、分母 4 または 8 |
| 音 | 短いサイン波のクリックを内部生成 (1 拍目は高い音)。音量は独立して調整 |
| カウントイン | 0 / 1 / 2 / 4 小節 |
| 録音中のクリック | **切り替え式、既定はオン** (決定済み)。待機中に鳴らすかも切り替えられる |
| 出力 | Out 1-2 固定 (決定済み) |

- クリックは出力コールバック内で、サンプル数を数えて生成する (タイマーは使わない → 揺れない)。
- **カウントイン付きの録音開始**: 録音ボタン → カウントイン → 1 小節目の 1 拍目から書き込み開始。
  書き込みスレッドに「このフレーム番号から録る」と指示する (`StartAt(frame)`)。
  位置合わせの精度は「1 バッファ以内 + インターフェースの入出力遅延」。遅延ぶんの補正値 (ミリ秒) を
  設定で持てるようにする (既定 0)。
- カウントイン中はプリロールを使わない (両方オンのときはカウントインを優先し、その旨を表示)。
- `take.json` にテンポ・拍子・カウントイン小節数を記録する。DAW 側で同じテンポにすればグリッドに合う。
- 注意: ループバック入力 (M4 の In 7-8 など) を録音対象にしていると、クリックも録音される。
  メトロノームがオンでループバックらしき入力がアームされているとき、警告を出す。
  ただし **どの入力がループバックかはドライバから取得できていない** (cpal がチャンネル名を公開していない。
  未確認の回避策はあるが不安定)。当面は「5 番以降がアームされている」ではなく、ユーザーがトラックごとに
  付ける「ループバック」の印で判定する。

## 5. モニタリング (ミュート・ソロ・音量・パン) と波形表示

### 5.1 モニタリング

- トラックごとに **モニター (聴く/聴かない)・ミュート・ソロ・音量・パン**、全体に **マスター音量**。
- **既定はモニターオフ**。オーディオインターフェースのダイレクトモニター (遅延なし) を使う人が多く、
  アプリ経由のモニターは往復の遅延 (例: 48 kHz・256 サンプルで約 11 ms + 機器の遅延) があるため。
  オンにしたときは「インターフェース側のダイレクトモニターを切らないと二重に聴こえる」と案内する。
- 「録音しない (アーム)」と「聴かない (ミュート)」は別の操作。トラック行に両方のボタンを置く。
- ミュート/ソロの切り替えは 5 ms のフェードでつなぐ (プチノイズ防止)。

### 5.2 波形表示

- 入力コールバックで、チャンネルごとに一定フレーム数 (約 5 ms ぶん) の最小値・最大値を取り、
  波形用リングで UI に渡す。UI は直近 約 30 秒ぶんを保持する。
- トラック行のメーター部分を、**右端が現在で左へ流れる波形**に置き換える。
  待機中はグレー、録音中は赤。右端に細い縦メーターとピーク値を残す。クリップした箇所は赤い印。
- メトロノームがオンのときは、小節線と拍の線を波形の背景に引く。
- 録音中は「テイクの先頭から現在まで」の全体表示に切り替えられる (縮小して全体が見える)。
- マーカー: 録音中に `M` キーで現在位置に印を付ける。波形に旗を表示し、`take.json` と WAV の
  cue チャンクに書く (DAW で読める)。

## 6. VST プラグインは対象外 (決定)

エフェクトなど DAW でできることは DAW に任せる。recrec は「DAW 以外の、録音そのものに関わる機能」を揃える。
録音ファイルは常に生の入力のままにする。

## 7. 「録音に関する機能」の範囲

| 機能 | 版 | 備考 |
|---|---|---|
| メトロノーム、カウントイン、タップテンポ | v0.3 | |
| モニター、ミュート、ソロ、音量、パン、マスター音量 | v0.3 | |
| 波形表示、小節線、マーカー | v0.3 | |
| ループバック入力の印と警告 | v0.3 | |
| テイクの名前変更・メモ・削除 (ごみ箱へ) | v0.3 | 小さいので一緒に入れる |
| テイクの試聴再生 | 候補 | 出力エンジンがあれば小さく作れる |
| チューナー | 候補 | |
| 重ね録り (前のテイクを再生しながら録る)、パンチイン | 対象外 (要望があれば再検討) | 再生と録音の同期・編集が必要で、DAW そのものになる |
| 入力ゲインの変更、EQ、コンプ、VST プラグイン | 対象外 | 生の音を変えない方針。音作りは DAW で行う |

## 8. 画面への反映 (v0.3)

- 録音ボタンの横に **メトロノームの帯**: テンポ (数値 + タップ)、拍子、カウントイン、
  クリックのオン/オフ、音量。拍に合わせて点が光る。
- カウントイン中は経過時間の位置に「-2 | 3」のように小節と拍を大きく表示する。
- トラック行: `[録音] [モニター] [M] [S]  名前  ソース  ─── 波形 ───  メーター  音量  パン  削除`。
  幅が足りないときは音量とパンを行の展開部に移す。
- 左列に「モニター」: マスター音量、遅延補正、出力の状態。

## 9. 決定事項

- VST プラグインは入れない。
- クリックの出力先は Out 1-2 固定。録音中のクリックは切り替え式 (既定オン)。
- クリックは録音ファイルに入らない (出力にだけ流す)。ループバック入力を録音対象にした場合だけ混ざるので警告する。
- ミュートは「聴こえなくする (録音はされる)」。「録音しない」は従来のアームで行う。

## 10. テスト方針

- メトロノーム: 指定テンポ・拍子で、クリックの開始位置がサンプル単位で期待どおりであること (合成出力を検査)。
- `StartAt(frame)`: 指定フレームより前のサンプルがファイルに入らず、指定フレームが先頭になること。
- ミキサー: ミュート/ソロ/音量/パンの組み合わせで出力が期待値になること、切り替えがフェードすること。
- 波形: 既知の信号から最小値・最大値の列が正しく作られること、あふれても録音側の取りこぼしに数えないこと。
- 出力を開けない場合に録音が従来どおり動くこと。
- 実機 (MOTU M Series + ASIO): 入出力同時オープン、クリックと録音の位置関係、モニターの遅延。
